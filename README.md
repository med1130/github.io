# موقع الأستاذ محمد بلقاضي - Mohammed Belkadi Personal Website

مرحباً بك في موقعك الشخصي المهني. تم تصميم هذا الموقع ليكون نافذتك الرقمية الرسمية، متجاوباً، ثنائي اللغة، وسهل الصيانة.

## 📁 بنية المشروع
```text
mohammed-belkadi-website/
├── index.html           # الصفحة الرئيسية (الهيكل)
├── CNAME                # (اختياري) عند ربط نطاق خاص لاحقاً
├── README.md            # هذا الملف
├── css/
│   └── style.css        # التنسيقات والألوان (CSS3)
├── js/
│   ├── config.js        # [هام] ملف الإعدادات والبيانات المركزية
│   └── main.js          # منطق الموقع (اللغات، الروابط، vCard)
├── assets/
│   ├── images/          # الصور (صورة شخصية، أيقونة)
│   └── icons/           # أيقونات إضافية
└── files/
    └── contact.vcf      # ملف جهات الاتصال للتحميل
```

## 🛠 كيف تعدل بيانات الموقع؟

جميع بيانات الموقع موجودة في مكان واحد لتسهيل التعديل.

### 1. تغيير المعلومات الشخصية والروابط
افتح الملف `js/config.js` باستخدام أي محرر نصوص (مثل Notepad أو VS Code). ستجد قسماً اسمه `SITE_CONFIG`. يمكنك تعديل أي قيمة بداخل علامات التنصيص:
- **الاسم، المسمى المهني:** قم بتغيير النصوص العربية والإنجليزية.
- **روابط التواصل:** استبدل روابط `https://...` بروابط حساباتك الحقيقية.
- **بيانات الاتصال:** قم بتغيير رقم الهاتف والواتساب والبريد الإلكتروني.

### 2. تغيير الصورة الشخصية
1. ضع صورتك الجديدة داخل المجلد `assets/images/`.
2. تأكد من أن اسم الصورة هو `profile-placeholder.jpg` (أو أي اسم آخر).
3. إذا غيرت الاسم، افتح `js/config.js` وعدّل مسار الصورة في سطر `avatar: "assets/images/..."`.

### 3. تعديل الألوان
افتح الملف `css/style.css`. في بداية الملف ستجد `:root`. يمكنك تغيير قيم الألوان (Hex Codes) هنا:
- `--navy`: اللون الأزرق الداكن الرئيسي.
- `--gold`: اللون الذهبي للتفاصيل.
ستتغير الألوان في الموقع تلقائياً بمجرد حفظ الملف.

## 🚀 كيف تضيف منصة تواصل جديدة؟
1. في ملف `index.html`، أضف السطر الخاص بالمنصة في قسم `Social Media Section`.
2. في ملف `js/main.js`، أضف المتغير الجديد في قاموس الترجمة وقم بربطه في دالة `renderPage`.

## 🔄 كيفية تحديث الموقع بعد النشر
بعد إجراء أي تعديل محلي على جهازك:
1. ارفع الملفات المعدلة إلى مستودعك على GitHub.
2. سيقوم GitHub Pages بتحديث الموقع تلقائياً خلال دقيقة.

## 🔗 الربط بنطاق خاص (Custom Domain)
مستقبلاً، إذا اشتريت نطاقاً مثل `belkadi-elec.com`:
1. أنشئ ملفاً اسمه `CNAME` في المجلد الرئيسي (لا تضع له امتداد).
2. اكتب فيه اسم النطاق فقط (مثلاً: `belkadi-elec.com`).
3. اربط النطاق من إعدادات DNS لدى مزود النطاق بـ GitHub.
